## Decisions and fallbacks

- Retain Electron, but do **not** adopt `focusable:false` as proven idle behavior. It is opt-in via
  `SVARA_SPIKE_FOCUS_MODE=nonfocusable`. Requirement stays avatar-only, non-focus-stealing idle with
  inline typing and approvals. Do not silently replace it with a dashboard or permanent input window.
- Missing/nonpersistent portal grant: honest pending/re-consent state, not a bypass or promise of
  remembered grants. Computer use stays off by default.
- Missing accessibility/focus information: report unavailable, not fabricated app state.
- Failed shortcut: CLI/tray recovery once implemented; explicit opt-in for GNOME shortcut creation.
  A marker probe does not establish the future CLI's behavior.
- AEC unavailable/unproven: headphones or barge-in off; duck-and-gate needs its own test.
- Fractional scaling stays best-effort; 100/200% are targets, not both verified configurations.
- A GNOME extension or altered window UX requires a new design decision, not an automatic fix.

## 2026-10-02 — Managed input-hint candidate implemented

Branch: `fix/T0.10-foundation-gates`, based on main `23176a7`. The opt-in `managed-hints` mode
sets `WM_HINTS.InputHint=False` and removes only `WM_TAKE_FOCUS` while idle; it restores input and
that protocol for explicit Type/approval, preserving other WM hints/protocols. It does not call
Linux `setFocusable`. Window creation stays managed (`override_redirect=False`), above and shaped.
The helper runs only for the owned window, in a bounded subprocess, with serialized transitions.
Renderer IPC is now restricted to the owned spike renderer. Startup uses `showInactive`.

Actual environment: Ubuntu **24.04.5**, GNOME **46.0**, **X11**, x86-64. Read-only inspection found
one active X11 login session, no XWayland/nested compositor or running VM. QEMU is installed but no
26.04 VM image was found in Desktop/Downloads. This is not an exhaustive filesystem search and
does not claim a VM cannot be supplied later. The user's instruction was to use what is available;
no login-session switch or new VM installation was performed.

The capability probe reports AT-SPI names (Code, Brave and session components), running PipeWire
1.0.5 and both AEC libraries. Screenshot/RemoteDesktop/ScreenCast/GlobalShortcuts introspections
currently return no members. This does not repair or exercise a portal grant.

The regression initially matched Mutter's decorative frame instead of the client window; the
committed checker uses `wmctrl` client IDs. It resets stale interaction state and input sentinels
before replay and restores test state in cleanup. A launcher retest also exposed a fast-drag race:
the first pointer move could precede the window-position IPC response. The renderer now buffers
that move and replays it when the response arrives, provided the drag is still active. Three
consecutive combined focus regressions passed after the correction. The reproducible fixture is
in [the spike README](../../spikes/ubuntu-integration/README.md#managed-input-hint-candidate-2026-10-02).
Debug endpoints are loopback-only and temporary. No mic, clipboard, shortcut or system-service
changes were needed. The unrelated `:memory:.ses` remains untouched.

Local verification: Python lint/format/Pyright and 10 tests, Biome/TypeScript, 9 Vitest tests,
4 native-validation Node tests, desktop build, C compilation with warnings-as-errors, shell syntax,
plan structural validation and diff whitespace checks passed. The existing large-bundle warning
remains; it is not a product resource-budget pass. The launcher builds the helper in a private
temporary directory and forwards opt-in debug arguments; normal exit removes its helper and
stops the preview server.

G-PRESENCE has an implemented candidate with local X11 evidence; the existing default stays the
managed baseline until the same combined matrix passes against native Wayland applications on
24.04 and 26.04. The alternative transient-window mechanism is unnecessary for this X11 result;
evaluate it only if the candidate fails the Wayland matrix. Phase 0 has not exited.

## 2026-10-03 — Reproducible resource baseline
