# T0.9 — Python 3.14 dependency and native-runtime spike

Date: 2026-09-27
Result: **Python 3.14 gate passed**

The complete v1 Python runtime set from the implementation guide resolves to one `uv.lock`. A clean
host install with uv's `--no-build` gate proves the set is available as Linux x86-64 wheels, and it
runs on standard GIL-enabled CPython 3.14.7. All 19 direct runtime packages import successfully. The
four native paths called out by the roadmap also perform real work:

- ONNX Runtime loads an embedded 113-byte graph on the CPU provider and computes `2 + 1 = 3`.
- CTranslate2 queries the CPU backend and reports float32, int16, int8, and int8-float32 support.
- PyAV allocates and resamples a mono PCM frame from 16 kHz to 8 kHz through FFmpeg.
- dbus-fast marshals a `ListNames` method call into a 136-byte D-Bus wire message.

## Local model baseline

Measurements used local, already-downloaded model files on the primary Ubuntu 24.04 machine. Each
model was loaded in a fresh process on CPU; cold load includes importing its runtime and constructing
the model from the warm filesystem cache. RSS delta is measured immediately after construction.

| Model | Stored size | Cold load | RSS after load | RSS delta |
|---|---:|---:|---:|---:|
| Kokoro timestamped fp16 ONNX | 155.67 MiB | 2,233 ms | 512.99 MiB | 495.16 MiB |
| faster-whisper `small`, int8 CPU | 463.69 MiB | 1,782 ms | 559.27 MiB | 541.44 MiB |

These figures are development-machine baselines, not final packaged performance budgets. Model
download time is excluded, and Phase 3 still measures warmed inference latency and concurrent model
pressure in the composed voice pipeline.

## Reproduction

```bash
make setup
make smoke-deps

uv run --project core python spikes/dependencies/profile_models.py \
  --kokoro-model spikes/kokoro/.cache/model/model_fp16.onnx \
  --whisper-cache spikes/dependencies/.cache/faster-whisper-small
```

The smoke is deterministic and network-free after `make setup`. The profiling command downloads the
Whisper model when its ignored local cache is absent.
