# T0.8 — Kokoro timing and lip-sync spike

Date: 2026-09-27
Result: **Tier A timing path confirmed**

The pinned timestamped Kokoro v1.0 ONNX export produced real 24 kHz speech and one duration value for
every padded IPA token. Across five fixed sentences, rounding those durations and multiplying by a
600-sample decoder hop reproduced every waveform length exactly. The resulting 25 ms phoneme
timeline is suitable for the planned IPA-to-viseme engine.

## Measurements

The report compares two onsets:

- **Raw error:** audible RMS-envelope onset minus the model's first content-token onset.
- **Visible error:** audible onset minus the beginning of the renderer's 35 ms anticipatory attack.

Negative means the audio becomes audible before the corresponding mouth onset. Cross-correlation
independently finds the offset that best aligns the token activity mask with the 10 ms RMS envelope.

| Sentence | Tokens | Audio | Inference | Raw onset error | Visible onset error | Best envelope offset |
|---|---:|---:|---:|---:|---:|---:|
| Papa made a blue paper boat. | 33 | 2,125 ms | 1,601 ms | −40 ms | −5 ms | −50 ms |
| Bright morning light warmed the quiet garden. | 49 | 2,950 ms | 1,680 ms | −20 ms | +15 ms | −50 ms |
| Five velvet flowers shimmer beside the fountain. | 47 | 3,375 ms | 1,649 ms | 0 ms | +35 ms | −30 ms |
| She chose three crisp apples and two ripe pears. | 51 | 3,200 ms | 1,754 ms | −70 ms | −35 ms | −50 ms |
| Svara speaks softly, but every mouth shape stays clear. | 60 | 3,900 ms | 2,206 ms | −70 ms | −35 ms | −50 ms |

- Raw mean/max absolute onset error: **40 / 70 ms**.
- Visible mean/max absolute onset error after the 35 ms attack lead: **25 / 35 ms**.
- The visible result is below the plan's 45 ms audio-to-mouth threshold for all five sentences.
- Best cross-correlation offsets were consistently −30 to −50 ms, independently supporting an
  anticipatory visual attack rather than a delayed mouth response.

Envelope onset is a coarse observable, not phoneme-level ground truth. This spike confirms the frame
hop and whole-track alignment; the 30-sentence bilabial closure suite remains a Phase 3 acceptance
test. The hand-authored IPA map forces PP/FF closures to a peak weight of 1.0 for at least 40 ms.

## Renderer check

`@svara/avatar` now contains a shell-independent, pure `PerformancePlayer`. It interpolates viseme
keyframes, reads the 10 ms envelope on the same scheduled clock, gives PP/FF closures priority, and
retargets the 15 internal visemes to the five standard VRM vowel expressions. Unit tests cover clock
alignment, interpolation, envelope lookup, closure dominance, and track termination.

The first real sentence was played through Electron/WebAudio on the pinned real VRM. The shell
logged a 2,125 ms / 24 kHz performance with 63 viseme keys, and PipeWire showed the Electron stream
active on the physical JBL output. This remains a development probe; it does not change the
avatar-only production UI contract.

## Reproduction

```bash
sudo apt install espeak-ng
SVARA_PYTHON=core/.venv/bin/python bash spikes/kokoro/run.sh
corepack pnpm --filter @svara/desktop shell:probe
```

The script downloads only the three pinned, hash-verified model files into an ignored cache. It
creates five ignored WAV/JSON pairs and publishes the first ignored pair to the desktop probe.
