# T0.6 — Electron shell spike

Date: 2026-09-27
Status: **Paused — runnable checkpoint, measurements incomplete**

This is a deliberate handoff point, not the T0.6 result and not a shell decision. The branch has a
runnable Electron wrapper around the same renderer and production Vite bundle used by T0.5, but the
fair CPU/RSS comparison and the full interaction checklist still need to be completed. T0.7 must not
start until this document contains the completed comparison.

> **This is a shell benchmark, not the Svara desktop UX.** The control panel, status text, FPS
> measurements and test buttons are disposable instrumentation. The Phase 2 product surface remains
> avatar-only while idle, as specified in `docs/revamp/02-desktop-shell-and-ui.md` §2–3.

## Implemented at this checkpoint

- Electron 44.4.5 is pinned in the workspace lockfile.
- A transparent, frameless, fixed-size, always-on-top, skip-taskbar `BrowserWindow` loads the
  minified local production build.
- The renderer page detects either candidate shell and uses a context-isolated preload bridge.
- The preload exposes only validated input-shape updates and structured measurement events.
- Linux `BrowserWindow.setShape()` receives the avatar and diagnostic-panel rectangles.
- The avatar region uses Electron's native `-webkit-app-region: drag` behavior.
- The launcher owns the Vite preview process and cleans it up when Electron exits.

## Evidence collected so far

The partial run was on the same Ubuntu 24.04 GNOME/X11 host and real ignored VRM used for T0.5.
Electron reported Chromium 144.0.7559.179.

| Check | Partial evidence | Status |
|---|---|---|
| Production frontend build | TypeScript and Vite production build completed | Pass |
| Transparent window | The real VRM and panel composited over the desktop without a black rectangle | Pass on X11 |
| Always on top | X11 reported `_NET_WM_STATE_ABOVE` | Pass on X11 |
| Native input shape | Renderer reported `native input shape · 2 regions` | Implemented; click-through behavior still needs an explicit underneath-window test |
| WebAudio | `AudioContext` reached `running` at 48 kHz and emitted structured events | Pass |
| Speaking render probe | 58.90 fps, 10 dropped frames over 10.0 seconds | Preliminary only; aggregate CPU and RSS were not sampled |

The repository's lint, two unit tests, shell syntax check, and Node syntax checks for `main.cjs` and
`preload.cjs` passed during this checkpoint. No Electron or Vite process was intentionally left
running when work stopped.
